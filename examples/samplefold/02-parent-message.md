# Parent message, term-time leave

Fictional sample. Samplefold Community Primary School. Not for sending.

Channel: email. Tone: plain, warm.

Subject: Time off school in term time

Dear families,

A few classes lost several days last year to holiday in term time. We cannot authorise a holiday in term time. If you already have dates booked, tell the office before you go, so we know the child is safe.

If the trip cannot move, the absence will be marked unauthorised. We will not put that in a class newsletter, and we will not name children.

If you want to talk about a single case, ask for Priya Sen. Bring the dates. We will not promise an authorisation on the phone.

Samplefold Community Primary School
Office, 4 October 2026

This is a sample. A real school would check it against its own policy and the current attendance guidance before sending.
