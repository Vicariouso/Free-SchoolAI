# Curriculum note, for the website

Fictional sample. Samplefold Community Primary School. Not a real curriculum.

We teach one class per year. Reading is first each morning. Mathematics follows. The afternoon is the rest of the national curriculum, in an order the subject leads wrote down, not a theme we rename each half term.

Year 5 is the year we watch. Last year's attendance was lowest there, and the reading lead says the catch-up group is too big for one adult. That is a staffing note, not a claim about results. No published score is used in this sample.

What we will not write on the site: a list of topics the school has not agreed, a progress percentage, or an inspection grade. This school has none on file in this pack.
